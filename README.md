# Sistema de Inventario CNC Soluciones

Sistema web de gestión de inventario para repuestos CNC, desarrollado con Django 5.0 + PostgreSQL.

## Características

- Gestión de categorías y subcategorías jerárquicas
- Códigos internos automáticos basados en prefijos
- Parámetros técnicos dinámicos por repuesto
- Sistema de movimientos con trazabilidad de usuarios
- Generación de códigos QR para etiquetas
- Interfaz responsive optimizada para móvil
- Subida de fotos desde la cámara del celular

## Requisitos

- Docker Desktop
- Git
